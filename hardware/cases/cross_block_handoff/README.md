# Continuous Boundary Testcase

From the hardware directory, with Verilator 5.050 and an external run directory:

```bash
export SUPRA_ARTIFACT_ROOT=/absolute/path/to/hardware-runs
export SUPRA_VERILATOR=/absolute/path/to/verilator-5.050/bin/verilator
python3 -B scripts/run_testcase.py --case cases/cross_block_handoff/case.json \
  --run-id boundary-handoff --threads 8 --jobs 8
```

The provided case executes L31, post-processing, full L0 scout, and selected deep L1 without reset. The host packs actual post state, including token changes and precision; RTL computes scout probabilities, scores, selection and A8-to-A4 downgrades. Before L1, actual scout table and emitted metadata are preserved for independent C11 comparison. A copy of actual L0 hidden protects L1 input rows from earlier L1 writes. The case also checks actual scout embedding reads and both selected and unchanged cache positions.

`case.json` and its referenced payloads are sufficient. To regenerate them in an external directory:

```bash
python3 -B scripts/prepare_handoff_testcase.py --kind boundary \
  --output "$SUPRA_ARTIFACT_ROOT/prepared/boundary-handoff"
```

`initial.bin` is the fixed synthetic 16-prediction/two-block input generated by the C11 forward-postprocess reference. `post_expected.bin` is its independently generated C11 DDR expected image.

`scripts/prepare_handoff_testcase.py --kind boundary` prepares the commands and independent expected data. During RTL replay, L31 and the forward-postprocess testcase complete the current block. The host reads actual persistent state to pack the full 164-token scan input. L0 generates actual probabilities, scores, selected-layer tokens and precision; L1 consumes that metadata. Independent C11 expected data checks scan results, selected metadata, cache changes and the final hidden plane. Retained K scales start at BF16 2.0, while updated zero-key tokens have the quantizer's BF16 1.0 fallback; checking both values detects incorrect commits to unselected tokens.

The fixed case uses deep target 80, A8 limit 48, initial future-token attempts 1 and limit 2. Zero Transformer weights and synthetic embeddings isolate the control and memory connections.

Each run reports its status and measured counters in `data/summary.json`.
