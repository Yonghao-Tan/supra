# Continuous Regular Testcase

From the hardware directory, with Verilator 5.050 and an external run directory:

```bash
export SUPRA_ARTIFACT_ROOT=/absolute/path/to/hardware-runs
export SUPRA_VERILATOR=/absolute/path/to/verilator-5.050/bin/verilator
python3 -B scripts/run_testcase.py --case cases/in_block_handoff/case.json \
  --run-id regular-handoff --threads 8 --jobs 8
```

The provided case executes L31, post-processing, and the next L0 without reset. It compares independent C11 state/event/metadata bytes, checks actual embedding read addresses and counts against the metadata emitted by RTL, and compares the next hidden output. Future-token attempts, pending state and joint selection are part of the fixed control input. `case.json` and its referenced payloads are sufficient; preparation is optional.

To regenerate the same case in an external directory:

```bash
python3 -B scripts/prepare_handoff_testcase.py --kind regular \
  --output "$SUPRA_ARTIFACT_ROOT/prepared/regular-handoff"
```

`initial.bin` is the fixed synthetic 16-prediction/two-block input generated by the C11 forward-postprocess reference. `post_expected.bin` is its independently generated C11 DDR expected image.

`scripts/prepare_handoff_testcase.py --kind regular` adds an actual L31 execution before this post testcase, then executes L0 from the metadata emitted by RTL. Zero Transformer weights and a 64-entry synthetic embedding table isolate the control and memory connections. The next layer consumes the state produced by RTL.

Each run reports its status and measured counters in `data/summary.json`.
