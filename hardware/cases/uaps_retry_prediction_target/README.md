# UAPS Selection Tests

Run from the hardware directory:

```bash
python3 -B scripts/run_testcase.py --case cases/uaps_retry_prediction_target/case.json --run-id joint-rules --threads 8 --jobs 8
python3 -B scripts/run_testcase.py --case cases/uaps_retry_prediction_target/suppressed/case.json --run-id suppressed-history --threads 8 --jobs 8
```

Both cases use the full N8 top and DRAMSim3 LPDDR4-3200 (2 x 16-bit channels).
The supplied synthetic inputs and expected outputs are sufficient to run them.

The first case checks UAPS selection following head and state updates. The
`suppressed` variant checks token suppression. Each run compares the complete
2 MiB DDR image with the supplied reference.

Expected values are generated by the algorithm's candidate and selection
functions and the C11 state and metadata references.
`integration/hardware_adapter/uaps_reference_data.py` regenerates these inputs
when the algorithm dependencies are installed.
