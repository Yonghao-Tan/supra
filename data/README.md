# Open Data

This directory provides partial evaluation data for SUPRA's token-skipping and
mixed-precision execution. The [memory-access trace](gsm8k_feature123_layer.trace.xz)
records memory transactions generated by RTL execution, with DDR timing
simulated by DRAMSim3. It uses a captured LLaDA-8B-Instruct inference on GSM8K
test sample 102, selecting one Transformer layer during inference with
Feature 1+2+3 enabled. Token skipping reduces the number of token
rows processed, while mixed precision reduces data movement for low-precision
operands. The trace records
the resulting DRAM reads and writes, exposing their volume and timing for this
layer execution.

The XZ-compressed file contains the complete plain-text transaction trace. Each
line gives a hexadecimal byte address relative to the DDR aperture, `READ` or
`WRITE`, and the decimal DRAM cycle when submitted to DRAMSim3. Each transaction transfers 32 bytes;
the [LPDDR4 configuration](../hardware/config/ddr/lpddr4_3200_2x16_8gib.ini)
defines the cycle period and memory timing.

This is one example of the data available through the repository. Additional
[hardware cases](../hardware/cases/README.md) provide input memory images,
reference outputs and numerical and token-state records, while
[algorithm tests](../algorithm/llada/tests/) provide numerical reference checks.
The [model-capture examples](../integration/README.md#more-examples) connect
algorithm inference to RTL execution and generate further tensors,
reference outputs and memory-access traces for other requests and execution ranges.
